## OSPF建立故障排查
- 卡在down/init状态
	- 接口未使能ospf
		- netowork
	- 接口配置了静默接口配置
		- silent-interface
	- ACL或防火墙过滤了ospf报文
		- 协议号89
		组播地址224.0.0.5/224.0.0.6
	- NBMA网络未手动指定邻居
		- peer
	- 互联端口IP地址掩码不一致
	- 是否采用从地址建立邻居
		- 从地址无法建立邻居关系
- 卡在2-way/attempt状态
	- MA网络将进行DR/BDR选举（40S），非DR/BDR间不能进入下一状态
	- 所有路由优先级均为0，则不进行DR/BDR选举
		- ospf dr-priority 0
- 卡在exstart/exchange状态
	- 接口MTU不一致
	- 两端单播IP不可达
	- 互联链路质量差
	- RID冲突
- 卡在loading状态
	- MTU问题
		- 导致大LSU报文丢弃
		- 即使 DBD 交换完成，携带大量 LSA 的 LSU 也可能因 MTU 不匹配被丢弃
	- 请求的LSA校验错误或不可用
		- 例如 Router ID 冲突导致 LSA 混乱。可用 display ospf error 观察错误增长趋势，结合 display ospf brief 检查全网 Router ID 是否唯一
- 其他原因
	- 区域ID不一致
	- 区域类型不一致
	- hello/dead时间不一致
	- 认证失败
	- 网络类型不一致
	- 互联IP不在同一网段
	- NBMA/P2MP未指定邻居
	- 接口down，物理层或协议没有UP
	- CPU/内存过高导致设备没有多余资源处理OSPF报文
	- BFD会话DOWN
